KIBANA QUERY LANGUAGE (KQL) BLUEPRINT - PROJECT GHOST-HUNTER
Fokus: Deteksi DNS Tunneling (dnscat2) & Malicious DNS via Sensor Jaringan Zeek
1. Kueri Dasar: Memantau Trafik DNS pada Port Standar ke Domain Capstone
Gunakan kueri ini di kolom pencarian Kibana untuk memantau aktivitas DNS (Port 53) menuju infrastruktur atau domain yang diwaspadai dalam simulasi.

data.zeek.dns.id.resp_p : 53 AND data.zeek.dns.query : "*.tunnel.capstone8.com"

2. Kueri Spesifik: Deteksi Karakteristik Panjang Query (Anomali Panjang Karakter)
Tunneling sering kali menyisipkan data terenkripsi/ter-encode di dalam subdomain, membuat string query menjadi sangat panjang. Kueri ini mendeteksi query yang melebihi 60 karakter pada port DNS.

data.zeek.dns.id.resp_p : 53 AND data.zeek.dns.query_length > 50

3. Kueri Deteksi Eksfiltrasi: Volume Respon DNS Tidak Wajar
Record DNS normal (seperti A atau AAAA) berukuran kecil. Jika panjang badan respon (response_body_len) melebihi 1000 bytes, ini merupakan indikasi kuat adanya data exfiltration atau payload delivery terselubung.

data.zeek.dns.id.resp_p : 53 AND data.zeek.dns.response_body_len > 1000

4. Kueri Deteksi Interaktif (Command Execution via DNS)
Kueri kritikal untuk mendeteksi aktivitas Command and Control (C2) interaktif. Memburu paket DNS yang membawa tipe konten teks biasa namun mengandung string perintah sensitif Windows (seperti pengintaian sistem).

data.zeek.dns.id.resp_p : 53 AND data.zeek.dns.resp_mime_types : "text/plain" AND (data.zeek.dns.message : *cmd.exe* OR data.zeek.dns.message : *whoami* OR data.zeek.dns.message : *ipconfig*)

5. Kueri Komprehensif (Master Hunting Query)
Gunakan kueri gabungan ini untuk mencakup seluruh indikator anomali di atas dalam satu kali hunting di dashboard Elastic:


data.zeek.dns.id.resp_p : 53 AND (data.zeek.dns.query : "*.tunnel.capstone8.com" OR data.zeek.dns.query_length > 60 OR data.zeek.dns.response_body_len > 1000 OR (data.zeek.dns.resp_mime_types : "text/plain" AND (data.zeek.dns.message : *cmd.exe* OR data.zeek.dns.message : *whoami* OR data.zeek.dns.message : *ipconfig*)))

6. Logika Alerting Threshold (Untuk Konfigurasi SIEM / Kibana Alert)
Saat rules ini dipindahkan ke sistem Alerting automated, gunakan ambang batas berikut untuk menekan false positive:

Kondisi Utama: data.zeek.dns.id.resp_p == 53 AND data.zeek.dns.query_length > 50

Group by: data.zeek.dns.query atau data.zeek.dns.client_ip

Threshold: Jalankan alarm jika jumlah kueri (Doc Count) > 50 dalam durasi 1 menit ke rumpun subdomain yang sama, ATAU jika ditemukan kecocokan string perintah (whoami/cmd.exe) tanpa minimal threshold (Immediate Alert).
